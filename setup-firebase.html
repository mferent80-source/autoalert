AutoAlert — Firebase NOU (nu datorietrack!)

De ce nu merge cu datorietrack?
  • datorietrack = proiectul DatorieTrack (Firestore, fără Google Login)
  • AutoAlert are nevoie de Realtime Database + Google Sign-In
  • Amestecarea celor două apps în același proiect creează conflicte

Soluție: creează proiect Firebase separat numit autoalert

Pas 1 — Proiect nou

  1. Deschide Firebase Console
  2. Add project → nume: autoalert
  3. Google Analytics: opțional (poți dezactiva)

Pas 2 — Realtime Database

  1. Build → Realtime Database → Create Database
  2. Locație: europe-west1 (Belgia)
  3. Start in locked mode
  4. Tab Rules → șterge tot → lipește conținutul din database.rules.json (din folderul AutoAlert) → Publish

Pas 3 — Google Sign-In

  1. Build → Authentication → Get started
  2. Sign-in method → Google → Enable → Save
  3. Settings → Authorized domains → verifică că există mferent80-source.github.io (adaugă dacă lipsește)

Pas 4 — Web App config

  1. Project settings (roată) → Your apps → </> Web
  2. Nickname: AutoAlert → Register app
  3. Copiază blocul firebaseConfig și lipește mai jos

Lipește aici config-ul din Firebase Console:

Important: databaseURL trebuie să existe (RTDB activat la Pas 2).

Pas 5 — Publică pe GitHub

  1. Înlocuiește firebase-config.js în folderul AutoAlert cu fișierul descărcat
  2. În terminal (sau GitHub Desktop): commit + push la mferent80-source/autoalert
  3. Așteaptă 1 minut → testează app live
