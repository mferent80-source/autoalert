AUTOLERT DEPLOY - CITESTE ASTA
==============================

EROAREA 0x800700E8 = vine din CURSOR, nu din Windows.
NU rula deploy din Cursor! Foloseste una din metodele de mai jos.


METODA A - Explorer (2 dublu-click-uri)
---------------------------------------
1. Deschide folderul in Explorer (NU in Cursor):
   C:\Users\Cimin\AutoAlert

2. Dublu-click:  1_LOGIN.bat
   -> browser Google -> login -> revino in fereastra

3. Dublu-click:  2_DEPLOY.bat
   -> asteapta "GATA! AutoAlert e live!"


METODA B - Win+R (daca .bat nu se deschide)
-------------------------------------------
Apasa Win+R, lipeste UNA din comenzi, Enter:

Pas 1 - login:
C:\Users\Cimin\AutoAlert\1_LOGIN.bat

Pas 2 - deploy (DUPA login):
C:\Users\Cimin\AutoAlert\2_DEPLOY.bat


METODA C - Manual in CMD (Win+R -> cmd -> Enter)
------------------------------------------------
cd /d C:\Users\Cimin\AutoAlert\scripts

"C:\Program Files\nodejs\node.exe" "%APPDATA%\npm\node_modules\firebase-tools\lib\bin\firebase.js" login

"C:\Program Files\nodejs\node.exe" "%APPDATA%\npm\node_modules\firebase-tools\lib\bin\firebase.js" deploy --only database,hosting


Dupa deploy:  https://datorietrack.web.app
